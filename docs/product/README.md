# Product


本领域描述 LoopX 正成为的产品。它把持久稳定的 foundations 与运行时特定体验、运维者界面、使用场景和分阶段路线图分开,以免实验性观察被误当成稳定契约。

## 当前产品事实

- [产品愿景](vision.md):长程 Loop Agent、维护者优先的管理、evidence 与开源方向。
- [核心控制面图谱](core-control-plane/README.md):state、交互与有界上下文的产品与运行时地图。
- [发布就绪度](release-readiness.md):当前支持的 v0.x 安装与兼容边界。
- [发布说明模板](release-note-template.md):可直接使用的发布决策摘要、产品分组、可选能力指引、验证与双语署名格式。
- [公开采用 Loop](public-adoption-loop.md):从外部尝试到可查证的公开反馈路径。
- [领域能力包](domain-capability-packs.md):什么属于通用控制面,什么需要显式的领域包。
- [场景能力差距图](scenario-capability-gap-map.md):跨问题修复及其他的场景信号可复用的能力增量。

## 产品领域

- [Foundations](foundations/README.md):Agent 身份、规划、奖励、重规划和 server/client 形态。
- [Runtimes](runtimes/README.md):Codex CLI 以及未来的运行时体验。
- [运维者界面](surfaces/README.md):状态、可观测性、前场和展示边界。
- [使用场景](use-cases/README.md):自动研究、issue/PR 工作、跨运行时评审与办公运营。
- [路线图](roadmaps/README.md):提出的里程碑,并非当前运行时契约。
- [迁移与历史](migrations/README.md):命名与 state 迁移。

# LoopX 项目历史


本页记录改变 LoopX 身份、治理或稳定产品方向的里程碑。它不是逐提交 changelog；
普通发布变更属于[更新说明](../update-notes/README.md)与当前 checkout 的 git 历史。

## 公开时间线

本仓库尚未记录独立里程碑。这里当前为空是刻意的：本页只写本仓库自己交付、且能由
本仓库的 commit、tag 或 release 验证的事实。没有对应制品的条目不会出现在本页。

## 本历史如何维护

- 只有当里程碑改变项目身份、治理、发布线或持久产品契约时才添加。
- 每个事实声明都链接到本仓库的公开 commit、pull request、tag 或 release。
- 贡献者归属使用 Git 历史与 GitHub 的贡献者图；不要从提交计数推断人类身份或 maintainer authority。
- 私有运营上下文、原始轨迹、内部链接与本地路径远离公开时间线。

作者与贡献者归属见 [AUTHORS.md](authors.md)。

# LoopX 许可

> [English](licensing.md)

LoopX 自 `v0.4.8` 起以 Apache License 2.0 作为统一开源核心的主要许可证。当前完整许可证在 [`LICENSE`](https://github.com/huangruiteng/loopx/blob/main/LICENSE)，随项目分发的归属声明在 [`NOTICE`](https://github.com/huangruiteng/loopx/blob/main/NOTICE)。

## 版本边界

- `v0.4.7` 及之前的发布与 tag 在其受管辖的 MIT License 下永久可用。
- 自 `v0.4.8` 起，统一 LoopX 开源核心以 Apache-2.0 分发。
- 先前 MIT 许可证文本及其版权声明逐字保留在
  [`LICENSE-MIT`](https://github.com/huangruiteng/loopx/blob/main/LICENSE-MIT)。
  它们继续记录并管辖已授予历史 MIT 发布与最初按这些条款分发的部分的权益。

更改当前分发的许可证不会撤销或收窄先前发布已授予的权益。用户可以在其原始 MIT 条款下继续使用更早的 LoopX 发布。

## 为什么用 Apache-2.0

Apache-2.0 保持核心对商业与非商业使用宽松，同时为覆盖范围内的贡献增加显式专利许可框架。当模型提供商、基础设施团队与大型企业把 LoopX 作为共享长程 agent 基础设施采用或贡献时，这个更清晰的框架很有用。变更旨在让生态协作更容易，而不是限制商业使用。

该转变不会为仅按 MIT 条款贡献的人制造追溯性的 Apache 专利授予。Apache-2.0 的专利治理价值主要经由新发布线中分发的代码以及按 Apache-2.0 与 DCO 条款提交的未来贡献积累。历史版权与归属记录保持完整。

## 转变后的贡献

除非贡献者在提交前明确说明，否则未来被 LoopX 接受的贡献按 Apache-2.0 提交，如该许可证第 5 节所述。Pull request 中的每个提交还必须携带 Developer Certificate of Origin 1.1 sign-off。确切工作流与认证见 [`CONTRIBUTING.md`](https://github.com/huangruiteng/loopx/blob/main/CONTRIBUTING.md) 与 [`DCO`](https://github.com/huangruiteng/loopx/blob/main/DCO)。

本转变不引入贡献者许可协议或版权转让。版权仍归贡献者，就各自贡献持有。

## 开源核心与商业边界

本仓库的统一开源核心是 Apache-2.0。单独交付的 Managed Control Plane、企业专属模块、托管运维或实现与支持服务，在不属于本仓库 Apache-2.0 核心分发时，可以使用单独的商业条款。

Apache-2.0 本身在其条款下允许商业使用、修改与分发。[`TRADEMARKS.md`](https://github.com/huangruiteng/loopx/blob/main/docs/project/trademarks.md) 中单独的项目名与 logo 指引仍然适用；软件许可证不创造背书或商标权利。

本文档解释项目的公开许可政策，不是法律建议。
